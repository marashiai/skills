# skills

Personal Codex skills.

- [`cerebro`](cerebro/SKILL.md) delegates and supervises implementation through
  the Cerebro orchestrator.
- [`engineering`](engineering/SKILL.md) defines a disciplined engineering
  workflow focused on simple, production-ready changes.
- [`hashimoto-review`](hashimoto-review/SKILL.md), inspired by Mitchell
  Hashimoto's [whiteboard defense](https://x.com/mitchellh/status/2100249348345057389),
  audits customer-facing changes and annotates Hunk diffs for system-level
  understanding.
- [`supervise`](supervise/SKILL.md) coordinates repository work across issues,
  pull requests, reviews, and verification.
- [`writing`](writing/SKILL.md) edits prose while preserving the author's ideas
  and voice.

Each top-level directory is a self-contained skill.
